# PermaDemo

An **invented** hillside permaculture garden for study and testing, not a real
place (CC0). The reference site of the twin: it must always generate, and the
gates of each twin step are measured on it.

- About 25 % slope, falling to the south; four zones, three fascines in zone 2.
- Frame: the garden outline, with no-go areas around a bat roost, the pond and a steep bank.
- Vegetation map: five oaks, an orchard, a hazel, meadow, tall grass, a bramble
  thicket, a hedge and crop beds (classes from the ontology's perma:VegetationClasses).
- Four hidden objects (rocks, a branch) for exploration to find.

```bash
python3 tools/generate_world.py --site permademo
```
